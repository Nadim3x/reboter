🤖 Telegram Setup

  1. Message @BotFather on Telegram
  2. Send /newbot and follow prompts
  3. Copy the token and paste above
  4. Start your bot and send it a video link!

🚀 Zernio Setup

  1. Create an account at zernio.com and a profile
  2. Connect your Instagram (Business/Creator) and TikTok accounts to that profile
  3. Dashboard → API keys → create a key (sk_…) and paste it above
  4. Save, then use Check connection to confirm both platforms show ✅

Each upload = presign → PUT file → POST /v1/posts with publishNow.
