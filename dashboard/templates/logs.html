🎨 Log Colors

  • SUCCESS / posted — Upload succeeded
  • ERROR / FAIL — Upload failed
  • INFO — General info
  • WARNING — Non-critical issue

📊 Log Format

timestamp | url | caption | status | message
Example:
2024-01-15 10:30:00 | https://tiktok.com/... | Follow for more 🔥 | SUCCESS | Posted to 2/2

🔍 Troubleshooting

  • Invalid URL — Link not supported or private
  • Too large — Video exceeds 100MB limit
  • Unavailable — Video deleted or private
  • API error — Check Zernio key & endpoint
